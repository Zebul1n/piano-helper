## 1. Verdict

**Favorable avec réserves.** Rien n'empêche de démarrer I0 avec cette chaîne.

La chaîne décrite tient debout. Les versions figées existent : Gradle 9.9.0, AGP 9.5, NDK r30 LTS et CMake 4.1.2 sont présents dans le canal stable du SDK. Les sources tierces sont copiées dans le dépôt, sans sous-module ni LFS, ce qui garantit des sources complètes par étiquette. Enfin, GitHub Actions gratuit suffit pour le banc et l'émulateur.

**Aucune remarque bloquante. Six remarques majeures**, à corriger avant ou pendant I0 :

1. **Vérification des développeurs (10 §5).** La description est inexacte : l'application stricte ne vise pour l'instant que les boutiques participantes, et les installations par `adb` sont exemptées. Le chiffre de 20 appareils l'emporte sur celui de 50. Surtout, la diffusion large hors Play coûte 25 USD, ce qui heurte le budget nul.
2. **Contrôle 16 Ko incomplet.** Il manque le contrôle de la fin du segment RELRO, celui de l'alignement ZIP et un test sur une image système à pages de 16 Ko.
3. **Taille de l'APK sous-estimée.** L'AAR ONNX Runtime 1.31.1 pèse 34,2 Mo par ABI arm64, et il embarque quatre ABI.
4. **detekt 1.23.8 est probablement incompatible avec AGP 9.**
5. **Exécuteur `ubuntu-latest` non figé.** C'est incompatible avec la règle de non-régression à tolérance nulle et avec l'équivalence entre la CI et le poste.
6. **Protection de la clé de diffusion dans la CI insuffisamment spécifiée.**

## Annexe A — Contrôle 16 Ko proposé (Node.js, sans dépendance)

Le script a été essayé sous Node.js 24.14.1 sur les 8 `.so` de l'AAR ONNX Runtime 1.31.1 : les 8 sont `ALIGNED`, avec un code de sortie 0. À placer dans `tools/scripts/elf16k.mjs`. En CI, on décompresse l'APK, on lance le script sur `lib/arm64-v8a/*.so` et `lib/x86_64/*.so`, puis `zipalign -c -P 16 -v 4`.

```js
// Contrôle 16 Ko d'un .so ELF (alignement des segments LOAD et fin de GNU_RELRO).
// Usage : node elf16k.mjs fichier.so [...]   — code de sortie 1 si un fichier n'est pas conforme
import { readFileSync } from 'node:fs';
const PT_LOAD = 1, PT_GNU_RELRO = 0x6474e552, PAGE = 0x4000n;
let fail = 0;
for (const f of process.argv.slice(2)) {
  const b = readFileSync(f);
  if (b.readUInt32BE(0) !== 0x7f454c46) { console.log(`${f}: pas un ELF`); fail++; continue; }
  const is64 = b[4] === 2, le = b[5] === 1;
  const u16 = (o) => le ? b.readUInt16LE(o) : b.readUInt16BE(o);
  const u32 = (o) => le ? b.readUInt32LE(o) : b.readUInt32BE(o);
  const u64 = (o) => le ? b.readBigUInt64LE(o) : b.readBigUInt64BE(o);
  const phoff = is64 ? Number(u64(0x20)) : u32(0x1c);
  const phentsize = u16(is64 ? 0x36 : 0x2a), phnum = u16(is64 ? 0x38 : 0x2c);
  const loads = []; let relro = null;
  for (let i = 0; i < phnum; i++) {
    const o = phoff + i * phentsize, type = u32(o);
    const vaddr = is64 ? u64(o + 0x10) : BigInt(u32(o + 0x08));
    const memsz = is64 ? u64(o + 0x28) : BigInt(u32(o + 0x14));
    const align = is64 ? u64(o + 0x30) : BigInt(u32(o + 0x1c));
    if (type === PT_LOAD) loads.push({ vaddr, memsz, align });
    if (type === PT_GNU_RELRO) relro = { vaddr, memsz };
  }
  const minAlign = loads.reduce((m, l) => (l.align < m ? l.align : m), 1n << 62n);
  let relroOk = true;
  if (relro) {
    const end = relro.vaddr + relro.memsz;
    const host = loads.find((l) => relro.vaddr >= l.vaddr && relro.vaddr < l.vaddr + l.memsz);
    relroOk = end % PAGE === 0n || (host && host.vaddr + host.memsz === end);
  }
  const ok = minAlign >= PAGE && relroOk;
  if (!ok) fail++;
  console.log(`${ok ? 'ALIGNED  ' : 'UNALIGNED'} ${f} : LOAD min align 0x${minAlign.toString(16)}, RELRO ${relro ? (relroOk ? 'ok' : 'NON CONFORME') : 'absent'}`);
}
process.exit(fail ? 1 : 0);
```

```bash

```
