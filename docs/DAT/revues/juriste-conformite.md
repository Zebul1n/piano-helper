## 1. Verdict

**Prêt avec corrections.**

Le DAT traduit fidèlement la revue juridique du PRD : sources tierces copiées dans `third_party/` et archive de sources jointe à chaque diffusion (JUR-03), REUSE et `reuse lint` (JUR-15), écran des licences dès I0 (JUR-01), sauvegarde Android désactivée (JUR-02), son en mémoire vive (JUR-06), clé hors du dépôt (JUR-19). L'inventaire du 09 §5 est sérieux et daté.

**Un point est bloquant, sous condition.** Le binaire officiel d'ONNX Runtime pour Android (AAR de Maven Central, option A de l'ADR-0011 et de QO-50) **contient le module de télémétrie de Microsoft, activé par défaut**. Ce module crée un identifiant d'appareil persistant et stocke des événements dans une base SQLite locale. Cela contredit la règle « pas de télémétrie » (09 §1, US-CNF-01 CA4, ENF-CONF-02). Le point n'est bloquant que si l'option A est retenue pour les variantes bêta ou publique sans neutralisation.

Quatre corrections sont **majeures** : les mentions dues pour les composants inclus dans ONNX Runtime ; les sources correspondantes d'ONNX Runtime ; les obligations de la LGPL-3.0 §4 a) à c) pour Verovio ; le statut réel des fichiers Leipzig fournis par Verovio, qui sont déjà une version convertie de la police.

## 3. Réponses aux points du 09 §7
